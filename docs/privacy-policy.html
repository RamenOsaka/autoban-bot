AutoBan — Privacy Policy

Last updated: August 12, 2026

1. Overview

AutoBan ("the Bot") is a Discord moderation bot that automatically bans members who receive a designated forbidden role. This Privacy Policy explains what data the Bot collects, how it is used, how it is protected, and your rights regarding that data.

By adding the Bot to your Discord server, you agree to this Privacy Policy. This policy is designed to comply with Discord's Developer Terms of Service and Developer Policy, as well as applicable privacy laws including the GDPR, CCPA, and LGPD.

2. Data We Collect

The Bot collects and stores only the minimum data necessary for its core moderation functionality. All stored data is Discord-issued identifiers — no personally identifiable information is collected.

  • Discord Server ID (Guild ID): used to associate your server's configuration with the Bot.
  • Role IDs: IDs of roles designated by server administrators as forbidden roles that trigger automatic bans.
  • Channel ID: the ID of the log channel configured by a server administrator to receive ban notifications.

The Bot does not collect, store, or process usernames, display names, message content, user IDs, IP addresses, ban history, or any other personal information. Ban log messages are sent directly to the server's designated log channel on Discord and are not stored outside of Discord's platform.

Data received from Discord's Gateway API (such as member join and role update events) is processed in memory only and is not persisted beyond what is described above. The Bot does not use API Data to profile users, their identities, or their relationships with other users. API Data is never used for advertising, marketing, machine learning, or any purpose beyond providing the Bot's stated moderation functionality.

3. How Data Is Used

Collected data is used exclusively to:

  • Identify which roles should trigger an automatic ban on a given server.
  • Determine which channel to send ban log messages to.
  • Determine whether the Bot is active on a given server.

Data is never sold, licensed, shared with third parties, disclosed to data brokers or advertising networks, or used for any purpose outside of the Bot's stated functionality, in accordance with Discord's Developer Policy (rules 15–18).

4. Data Storage and Security

Server configuration data is stored in an encrypted file on a private server. Data is encrypted at rest using AES-256-GCM symmetric encryption, in compliance with Discord's Developer Terms of Service (Section 5(c)) and applicable data protection regulations.

The encryption key is stored separately from the data file and is never exposed in source code or public repositories. No automated backups of configuration data are created or stored externally. Access to the data is restricted to the Bot operator only.

5. Data Retention and Deletion

Configuration data for a server is retained only for as long as the Bot remains on that server. When the Bot is removed from a server (kicked or banned), all configuration data associated with that server is automatically and permanently deleted from storage without any action required from the server administrator.

Data can also be deleted at any point using the /deletedata slash command through discord. If for any reason server administrators need to, they may also request manual deletion of their server's data at any time by contacting us at the email address listed in Section 10. Requests will be fulfilled within 30 days, and confirmation of deletion will be provided upon request.

If the Bot ceases operation entirely, all stored data will be permanently deleted within 30 days of the Bot going offline.

6. Data Sharing

API Data obtained through Discord is never shared with any third party except as required by applicable law or regulation. No service providers have access to stored configuration data. In the event that we are required by law to disclose data, we will notify affected parties to the extent permitted by law.

7. Security Incidents

In the event of unauthorized access to or use of any stored data, affected server administrators will be notified promptly to the extent required by applicable laws and regulations. Discord will also be notified as required by Section 5(c) of the Developer Terms of Service.

8. Discord's Role

The Bot operates on Discord's platform and is subject to Discord's Privacy Policy. The Bot does not bypass or circumvent Discord's privacy, safety, or security features, and respects all user and server decisions to remove or block the Bot.

9. Children's Privacy

The Bot is not directed at individuals under the age of 13 or the minimum age required by applicable law in their jurisdiction. The Bot operates exclusively at the server configuration level set by administrators and does not collect, store, or process any personal data belonging to individual Discord users, regardless of age. Server administrators are responsible for ensuring their server complies with applicable laws regarding minors.

10. Your Rights and Contact

Depending on your jurisdiction, you may have rights regarding your data, including the right to access, rectification, erasure, and data portability under the GDPR, CCPA, or other applicable laws. Since the Bot stores only Discord-issued server and role identifiers (not personal data), most of these rights are satisfied by the automatic deletion described in Section 5.

For questions, data deletion requests, to report a violation, or for any other privacy-related concerns, please contact us at:
autoban.privacy@gmail.com

We aim to respond to all requests within 30 days.

Continued use of the Bot after changes are posted constitutes acceptance of the updated policy. Material changes will be communicated via bot notifications and GitHub repository where possible.
